# PlanMyTrip – Smart Trip Planner & Expense Splitter 🌍✈️

PlanMyTrip is a modern, full-stack travel-planning web application combining:
1. **AI-Powered Itinerary Generation** using **NVIDIA Nemotron 3.5** (`nvidia/nemotron-3.5-lightning-30b-a3b`).
2. **Real-World Attraction Discovery** powered by **OpenStreetMap**, **Nominatim**, and **Overpass API**.
3. **Interactive Route Logistics & Maps** using **React Leaflet** and **OSRM Driving Routing**.
4. **Day-wise Editable Itineraries** with activity editing, removal, custom additions, day moving, and AI day-regeneration.
5. **AI Route Optimization** to cluster attractions geographically and eliminate unnecessary transit.
6. **Financial Budget Dashboard** with Recharts pie and bar charts for estimated vs. actual expenses.
7. **Splitwise-Style Expense Splitter** with equal/custom splits, net balances, and minimal debt-simplification settlements.
8. **Browser Persistence** using robust Local Storage.

## 🚀 Quick Start Guide

### 1. Prerequisites
- **Node.js** v18+ (tested on Node v26)
- **npm** v9+

### 2. Installation

Clone or open the repository root:
```bash
# Install backend dependencies
cd server
npm install

# Install frontend dependencies
cd ../client
npm install
```

### 3. Environment Configuration

In `server/.env` (or copy from `server/.env.example`):
```env
PORT=5001
NVIDIA_API_KEY=your_nvidia_api_key_here
```
> **Note:** To obtain a free NVIDIA NIM API key, visit [build.nvidia.com](https://build.nvidia.com) and generate an API key. You can also configure or test your API key live within the app's **Settings & API Key** dialog!

### 4. Running the Application

Open two terminal tabs:

**Terminal 1: Start Backend Server**
```bash
cd server
npm run dev
# Running on http://localhost:5001
```

**Terminal 2: Start Frontend Client**
```bash
cd client
npm run dev
# Running on http://localhost:5173
```

Now open [http://localhost:5173](http://localhost:5173) in your browser.

## 📱 Features Walkthrough

### Page 1 – Landing Page (`/`)
- Hero banner with travel destination background.
- Main heading: *"Your next adventure starts here."*
- Trip search bar with destination, travel dates, travelers, and budget.
- Popular destinations grid (**Goa**, **Manali**, **Jaipur**, **Bali**, **Kashmir**) with 1-click exploration.

### Page 2 – Create Your Trip (`/app/create`)
- Live Nominatim autocomplete destination search.
- Date range picker with automatic trip duration calculation.
- Budget per person and total group budget preview.
- 6 Travel Styles (Adventure, Relaxation, Luxury, Budget, Cultural, Nature).
- 8 Multi-select Interests (Food, History, Shopping, Beaches, Mountains, Wildlife, Photography, Nightlife).
- Comprehensive summary before generation.
- Animated 4-stage loading screen communicating live Overpass and Nemotron operations.

### Page 3 – AI-Generated Itinerary (`/app/itinerary`)
- Hero card with destination cover, travel style, duration, and budget.
- AI-Generated badge.
- Day-by-day tabs organized by **Morning**, **Afternoon**, and **Evening** schedules.
- Attraction cards with imagery, suggested time, fee, category, and description.
- **Interactive edits**: Edit place, delete place, add custom place, move between days.
- **Regenerate Day with AI**: Fresh activities generated by Nemotron without repeating prior places.
- **Optimize Trip**: Geographically reorders attractions to reduce travel distance and drive time, providing an accept/reject comparison modal.

### Page 4 – Interactive Map (`/app/map`)
- React Leaflet integration with OpenStreetMap tiles.
- Custom numbered pins colored by day.
- Real driving route polylines calculated via OSRM.
- Route distance and travel duration summary (distinguished from live traffic).
- Attraction navigator panel with 1-click locate & popup cards.

### Page 5 – Budget Planner (`/app/budget`)
- 4 Financial Summary Cards: Total Estimated Budget, Actual Expenses, Remaining Budget, Cost Per Person.
- Recharts Expense Distribution **Pie Chart**.
- Recharts Estimated vs. Actual **Bar Chart**.
- Interactive Category Budget Editor (Accommodation, Food, Transportation, Activities, Miscellaneous).

### Page 6 – Expense Splitter (`/app/expenses`)
- Splitwise-inspired group expense manager.
- Group traveler management (add, edit name, remove, view spending).
- Add Expense modal with **Equal Split** or **Custom Split**.
- Accurate net balance calculation per member (positive = receives money, negative = owes money).
- Automatic minimal debt settlement suggestions (`Who owes whom`).
- Balances guaranteed to sum to ₹0.

### Page 7 – Saved Trips (`/app/trips`)
- LocalStorage trip collection.
- View, Duplicate, and Delete actions with safety confirmation modals.
- Fully persisted across browser restarts and refreshes.

## 🛡️ API Endpoints Reference

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/itinerary/generate` | Generates full itinerary via Overpass + NVIDIA Nemotron |
| `POST` | `/api/itinerary/regenerate-day` | Regenerates a single day with AI |
| `POST` | `/api/itinerary/optimize` | Calculates optimal TSP route ordering |
| `GET` | `/api/places/search?q=:query` | Nominatim place autocomplete |
| `GET` | `/api/places/attractions` | Overpass real-world attractions query |
| `POST` | `/api/routes/calculate` | OSRM driving route polyline & distance |
| `GET` | `/api/config/status` | Server health and NVIDIA API key status |
| `POST` | `/api/config/verify-key` | Validates NVIDIA NIM API key connectivity |
